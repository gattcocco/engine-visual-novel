Heila! Progetto per una demo di una visual novel con elementi di avventura testuale, esempio: "prendi la chiave. Usa la chiave".
Per svilupparlo sto usando Django in maniera creativa, non per gestire info utenti di un sitoweb (ad esempio) ma per gestire le scene e gli oggetti.
Il nome del progetto quando vedrà la luce sarà Doki Doki Django Bulk (anagramma di Club con aggiunta di k).
Infatti il gioco si ispira a Doki Doki Literature Club.
